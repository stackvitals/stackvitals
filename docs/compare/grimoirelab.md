# StackVitals and GrimoireLab

GrimoireLab: CHAOSS's software-analytics toolset: 30+ sources, identity merging and community-health dashboards. Active (1.23.0 in October 2026). No DORA metrics.

**Kind:** Open source (GPL-3.0), self-hosted. **How it runs:** Docker Compose with MariaDB, Valkey and OpenSearch; 2 CPUs and 8 GB of memory.

Checked 2026-11-01 from the sources below; tools change, so check them before you rely on this.

## Where GrimoireLab is better

- Far broader sources (mailing lists, chat, Gerrit, Bugzilla).
- Merges people's identities and affiliations; CHAOSS-standard metrics at Linux Foundation scale.

## Where StackVitals differs

- DORA, flaky-test triage and pull request flow, which GrimoireLab doesn't do.
- A Community module with first-response times, and a CHAOSS mapping (docs/chaoss.md).
