# StackVitals and Faros Community Edition

Faros Community Edition: An engineering-operations platform (Airbyte, Postgres, Hasura, Metabase, dbt, n8n). Its repository and docs site were gone on 2026-11-01; the last release was v0.6.0 in May 2023.

**Kind:** Open source (Apache 2.0), withdrawn. **How it runs:** A Docker Compose stack of seven services (4 CPUs and 4 GB of memory recommended).

Checked 2026-11-01 from the sources below; tools change, so check them before you rely on this.

## Where Faros Community Edition is better

- A deep shared schema across many tools, with GraphQL and editable dashboards (when it was live).

## Where StackVitals differs

- Maintained; nothing to host.
